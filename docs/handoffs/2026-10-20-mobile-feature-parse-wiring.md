## Cleartext config

`app.json` plugin entry, verified against the SDK 57 docs (`https://docs.expo.dev/versions/v57.0.0/sdk/build-properties/`):

```json
["expo-build-properties", { "android": { "usesCleartextTraffic": true } }]
```

After prebuild, `android/app/src/main/AndroidManifest.xml` has `android:usesCleartextTraffic="true"`. The docs do not say the key can be limited to release builds, so it applies to every build type.

## Server address build steps

Full steps in `docs/release.md`. Short version: emulator needs nothing. For a phone, find the laptop's Wi-Fi IPv4 (`ipconfig`), then in the same shell as gradle:

```
source scripts/android-env.sh
export EXPO_PUBLIC_SALO_SERVER=http://<laptop-ip>:8787
cd android && ./gradlew assembleRelease -x lintVitalAnalyzeRelease
```

Not checked: a phone build with a LAN address (only the emulator default was built and run).

## Timeout: 8000 ms (coordinator instruction)

The orchestrator reported a real proxy call at about 3.2 s, so the parser's 4 s default would fall back too often. The post screen passes `timeoutMs: 8000` (`PARSE_TIMEOUT_MS` in `src/config/server.ts`). `src/parse` was not edited. The busy label says the message is being read, and the rule-based fallback still runs after 8 s. This is longer than the spec's "≤ 4 s" line. Recorded here as the orchestrator asked.

## Open risks

- The 8 s timeout is the orchestrator's number; it differs from the spec's "≤ 4 s". It makes the busy wait longer than the spec allowed.
- `src/donor/fromParsed.ts` imports the post form's catalog (`CATALOG`), which is built from all 30 evenings. This is the post form, not the parser, so it is outside the parser rule, but the catalog still reads pilot and main lots. This is the same catalog the manual form already uses.
- The `missing_unit` and no-match chip lists are based on name overlap (`candidatesFor`). A text that shares a short word with a catalog item will offer that item as a chip. The donor still has to tap a chip.
- `android/` was regenerated (cleared and recreated by prebuild). Any hand edits there would be lost; there were none.
- `app.json` was rewritten as JSON with expanded arrays, so the diff is larger than the three changes.
