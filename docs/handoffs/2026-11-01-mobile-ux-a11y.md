## Correction: no line-height wrapper

An earlier version of this pass added a `Text` wrapper that scaled fixed `lineHeight` by the font scale. It is removed, and every file is back on `import { Text } from 'react-native'`. The reason: React Native on Android already scales `lineHeight` when font scaling is on, so the wrapper would have scaled it twice.

Source: `node_modules/react-native/ReactAndroid/src/main/java/com/facebook/react/views/text/TextAttributes.kt`, `effectiveLineHeight`, line 83: `if (allowFontScaling) PixelUtil.toPixelFromSP(lineHeight, effectiveMaxFontSizeMultiplier)`.

So the `TYPE` line heights in `src/theme/tokens.ts` are unchanged and do scale. What is still open is whether any of them clip at 200%. That is a device check (below).

## What changed, shared parts

- **Reduced motion** (`src/a11y/reduceMotion.ts`): `watchReduceMotion(source, onChange)` is the pure part (AccessibilityInfo query plus the `reduceMotionChanged` listener; a stale first answer is ignored; a failed query keeps motion on). `useReduceMotion()` is the hook. `src/theme/theme.tsx` uses it; it already did the same work inline, so behaviour is unchanged. `src/app/_layout.tsx`: the screen transition is `'none'` under reduced motion instead of `'fade'` (CC-10). Already reduce-aware before this pass: the receipt-tape bar growth, the tape and lot-strip auto-scroll, and the policy sheet fade.
- **Truncation removed** (essential text is no longer cut at any font scale): dashboard header food name, lot-strip chip name, donor tag item name and English subtitle and pantry line, pantry tag item name, sticker text, journey station label.
- **Map labels** (`src/live/labelLayout.ts`, pure): greedy collision pass in priority order (donors, then pantries, then drivers; ties by input order). Four positions tried: right, left, above, below. A position is rejected if it touches a placed label, any marker, or the map edge. If all four fail, the label is hidden (the places table still lists it). `src/components/MapPanel.tsx` uses it; legend swatches are hidden from TalkBack.
- **Notification icon** (`assets/images/notification-icon.png`, `app.json`): 96x96 all-white PNG with transparency, derived from the alpha channel of `assets/images/android-icon-monochrome.png` (crop to the glyph, area-averaged resample, colour forced to white). The preview is a clean price-tag silhouette with the string intact. `app.json` plugin entry: `"expo-notifications": { "icon": "./assets/images/notification-icon.png", "color": "#1947b8" }`, per the SDK 57 notifications docs (Android only; needs a new native build).
- **Sticker** (`src/components/Sticker.tsx`): new `live` prop. By default the sticker is hidden from TalkBack (its card or tag already speaks the state). With `live`, its text is announced when it changes on its own.
