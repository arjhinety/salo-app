# Salo (Android app)

This is my Android app for **Salo**, the multi-agent food rescue system I'm building for CS 403 (Intelligent Agents) at the Technological Institute of the Philippines – Quezon City, 1st Semester S.Y. 2026–2027. Donors post surplus food, pantries and volunteer drivers bid as agents, and a live dashboard shows the evening unfold.

Status: early setup. All businesses, pantries, people and numbers in the app are simulated, from my [Salo Evening Dataset](https://huggingface.co/datasets/arjhinety/salo-evening-dataset).

## Run it

Requirements: Node 24, the Android SDK with an emulator or an Android phone (USB debugging), and a JDK.

```bash
npm install
npm run android      # builds the development app and installs it on the emulator/phone
npm start            # starts the dev server for an installed development build
npm run typecheck
npx expo lint
```

Built with Expo SDK 57 and Expo Router. The `android/` folder is generated by Expo and not committed.
